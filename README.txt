ギャンブル収支管理PWA Ver8.38

主な変更
- 投資と回収を「現金」「持ち玉／持ちメダル」に分離して入力・保存
- 既存の投資／回収データは旧形式から自動互換
- 持ち玉／持ちメダルは貸出・交換条件から円換算
- 記録保存時に貸出・交換条件をスナップショット保存し、後から店舗設定を変更しても過去記録を変えない
- ノリ打ちの自分の投資額は現金投資のみを使用し、持ち玉投資は除外
- ユーザー提供の store-data.json を同梱
- 収支表示の100円単位切り捨て設定、ツールページは継続

起動
起動.bat を実行してください。

データ
収支データはブラウザのローカルストレージに保存されます。重要なデータは設定画面からバックアップしてください。
