ギャンブル収支管理 PWA Ver8.40

変更内容
- ツールページを追加・整理。
- ツールは基本的に折りたたみ式で、選択すると展開して使用できる構成に変更。
- 小役・ボーナス・示唆カウンターをPWAへ統合。
- 機種別プリセット、総ゲーム数、出現率、項目の直接編集、ドラッグ並べ替え、削除、カスタム合算に対応。
- 合算にも出現率を表示。合算元は機種ごとにカスタム可能。
- カウンター専用データはPWAのlocalStorageに保存。
- Service Worker cacheをv8-39へ更新。

Ver8.42: 小役・汎用プリセットを追加。カウンターを記録日＋機種単位でその日の収支に紐づけ保存し、日報に表示します。

Ver8.44: 日報に表示された保存済みカウンター情報を機種ごとに削除できる「削除」ボタンを追加。削除前に確認ダイアログを表示します。
